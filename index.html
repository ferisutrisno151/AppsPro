Bagikan & Kolaborasi Proyek

Aplikasi ini menyimpan seluruh data secara lokal di perangkat Anda. Untuk berbagi dan berkolaborasi bersama rekan kerja:

  1. Klik tombol Export JSON di header atas untuk mendownload file data (.json).
  2. Kirimkan file JSON tersebut ke rekan kerja Anda via WhatsApp, Email, atau Google Drive.
  3. Rekan kerja Anda membuka file HTML LogistikPRO ini di perangkat mereka, lalu klik Import JSON untuk memuat data terbaru Anda.
Tips Kolaborasi: Anda juga bisa menaruh file HTML ini di folder bersama (Google Drive / OneDrive) agar dapat diakses bersama tim proyek.
