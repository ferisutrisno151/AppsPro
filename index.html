Install Aplikasi ke HP (PWA / APK)

Aplikasi LogistikPro dapat langsung dipasang sebagai aplikasi mandiri di HP Android/iPhone Anda:

Pengguna Android (Chrome):

  1. Buka link LogistikPro melalui browser Google Chrome.
  2. Ketuk titik tiga () di kanan atas browser.
  3. Pilih "Install Aplikasi" atau "Tambahkan ke Layar Utama".

Pengguna iPhone / iOS (Safari):

  1. Buka link melalui browser Safari.
  2. Ketuk ikon Bagikan (Share) di bagian bawah layar.
  3. Pilih "Tambahkan ke Layar Utama" (Add to Home Screen).
